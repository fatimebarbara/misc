Eight Standing Analyses

What HEDERA measures on every reporting cycle, why each indicator exists, and the prompt that rebuilds the report from the refreshed data.

Fictional worked example. The Health, Enthusiasm, Deadlines & Edible Resources Executive Agency does not exist. Its six programmes and its data are invented for a data-analysis exercise. The reporting mechanics are real; the agency is not.

The reporting cycle

HEDERA reports on its own performance on two fixed cycles. A monthly note goes to the Directors' Committee on the second Tuesday of each month, covering the eight indicators below at agency and programme level. A semester review in January and July does the same over a longer window and feeds the Annual Activity Report.

The content of both is identical in structure. Every edition covers the same eight indicators, in the same order, computed the same way, from the same workbook. That is deliberate: the value of a recurring analysis lies in being comparable with the last one, and an indicator that changes definition between editions tells you nothing about whether performance moved.

This document defines the eight. It states what each indicator measures, why the Committee needs it rather than merely enjoys it, what the output shows, which sheets it is computed from, and the corporate target it is judged against. It contains no findings — the figures live in the periodic report, and this document is what tells you how to read them.

The targets are round on purpose: 100 days to grant, 30 and 60 days to pay, 90% of reports on time, error rate under 2%. A target nobody can recite is a target nobody manages against.

The prompt that rebuilds the report

paste · attach the workbook · about a minute

The definitions above hold from edition to edition. This is the instruction that turns a refreshed workbook back into the finished report — the same eight indicators, the same house style, the same comparison against the previous period.

Prepare the periodic performance report for the HEDERA Directors'
Committee. The workbook is attached.

# Data
Use only the attached workbook. Sheets: Calls, Proposals, Evaluations,
Grants, Payments, Reporting, Amendments, Audits, Beneficiaries,
TrainingEvents, Helpdesk, StaffCapacity, BudgetExecution, KPITargets,
Survey. Keys: Call_ID, Proposal_ID, Grant_ID, Org_ID, Programme_Code.
Treat the current year as partial and label it year-to-date; compare
like-for-like periods only. Never estimate a figure you can compute,
and never carry a number forward from a previous edition.

# Output
One self-contained HTML page in the house style (ivy green #0F8461,
Zilla Slab headings, Source Sans 3 body, IBM Plex Mono for figures;
light and dark themes).
Structure: KPI strip → the eight indicators in fixed order →
a decisions-requested list → a spoken opening.

# The eight indicators, in this order
1. Time to grant against the 100-day target
2. Payment timeliness against 30 and 60 days
3. Budget execution and year-end commitment bunching
4. Call demand and success rate against the 15% floor
5. Reporting compliance against 90% on time
6. Widening participation against the 25% target
7. Assurance: audit error rate, corrections, amendment load
8. Capacity: workload per FTE, service load, delivery cost

# For each indicator, four things and nothing else
- THE FIGURE. One sentence, agency level, leading with the number,
  flagged against KPITargets: on target / watch / off target.
- BY PROGRAMME. Compare all six. Name the best and the weakest
  explicitly; a programme that moves against the agency trend is
  the finding, so say so.
- SINCE LAST PERIOD. Compare with the previous edition's window on a
  like-for-like basis. State the direction and the size of the move.
  Where a KPI moved more than 10%, say what in the data explains it
  and name the sheet and column you checked. If nothing in the data
  explains it, say that instead of guessing.
- WHAT I WOULD DO. One recommendation, specific enough to act on,
  or one thing genuinely worth highlighting as good news. Never both,
  never neither.

# House rules
- Euro amounts: €1.2m / €340k. Percentages one decimal. Days whole.
- Measured tone. No superlatives, no "significantly", no exclamation.
- Every claim traceable to a sheet and column; name them inline.
- Where a figure rests on fewer than 20 records, say so in the text.
- End with three to five decisions the Committee is asked to take,
  each tied to the indicator that produced it.

# Then
Give me a 90-second spoken opening covering only what moved.
1

Refresh the workbook. Same sheet names, same column headers, new rows. Nothing in the prompt changes between editions.

2

Attach it and paste the prompt. Add one line at the top if this edition has a specific worry: "Focus indicator 2 on Q4 — the Director asked about December."

3

Read the "since last period" lines first. They are the part you did not already know, and they come from a comparison you would otherwise have made by eye.

4

Argue with one number. Ask where it came from. The answer names a sheet and a column, and either the number survives or you have found something.

5

Keep your edits. When you change the wording of an indicator, paste that change into the prompt for the next edition. The prompt gets better; the work gets shorter.

Why the prompt is built this way

It carries four things a request for "a summary of my data" does not: the source and its keys, so joins are made rather than guessed; the fixed structure, so the edition is comparable with the last one; the house style, so the result circulates without re-editing; and an explicit instruction for the hard case — what to do when a number moves and nothing in the data explains it. That last line is what stops a confident sentence from being invented.
