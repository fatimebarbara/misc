How to create a PowerPoint presentation in GPT@EC

with the PowerPoint outline prompt

Purpose

Below are clear step-by-step instructions on how to use the PowerPoint presentation outline prompt.

Use this prompt when you already have a document containing information about a policy, project, initiative or topic, and you want to quickly turn it into a structured PowerPoint outline.

This method helps you create a solid starting point for a presentation without having to draft all slides manually.

Step-by-step instructions

Step 1: Start a new chat with the prompt

  • Go to GPT@EC.
  • Open the Prompt library
  • Search for PowerPoint presentation outline (SCIC)
  • Click on the button Start new chat

Step 2: Upload your source document

  • In the new chat, click on the + symbol and select Upload files.
  • Select the document you want to use.
Example:
  • a policy document
  • project documentation
  • annual learning orientations
  • background notes
  • briefing material

This document will be used by GPT@EC to generate the outline for your presentation.

Step 3: Run the prompt

After uploading the file, run the prompt. GPT@EC will analyse the content of your document and generate a PowerPoint outline based on it. At this stage, GPT@EC gives you a draft outline, not a finished slide deck.

Step 4: Copy the generated output

  • Select the full outline produced by GPT@EC.
  • Copy the text.

Step 5: Paste the outline into a text file

  • Open a plain text editor such as Notepad.
  • Paste the copied outline into the file.
  • Save it as a text file (for example, presentation_outline.txt).

Step 6: Open PowerPoint

  • Start Microsoft PowerPoint.
  • Open a new blank presentation.

Step 7: Import slides from the outline

This is the important part in PowerPoint:

  • Go to Insert
  • Click New Slide
  • Choose Slides from Outline

Then:

  • Select the text file you just saved
  • Click Insert

PowerPoint will automatically create slides based on the outline.

Step 8: Review the generated slides

PowerPoint will create a slide deck from the structure in the text file. This gives you a quick first draft of the presentation.

Important note

The result will not be perfect from the start.

Typically:
  • the content structure is useful
  • the layout is basic
  • the visual design is not yet adapted to your needs

Think of this as a starting point, not a final presentation.

Step 9: Improve and adapt the presentation

After the slides are created, you should:

  • review the wording
  • shorten or simplify text where needed
  • reorganise some slides if necessary
  • improve the flow of the story
  • add visuals, charts or images
  • apply the appropriate European Commission template

You can then adjust the layout in PowerPoint using the relevant Commission presentation template.

Example use case

This method is especially useful when you need to create presentations from existing documentation.

For example:

  • you need an overview of several projects
  • you already have extensive background documents
  • you want to quickly produce a first presentation draft

In that case, you can:

  1. upload the background documents to GPT@EC
  2. generate an outline
  3. import it into PowerPoint
  4. refine the content and design afterwards

This can save considerable time when preparing presentations.

Summary

Using the PowerPoint presentation outline prompt in GPT@EC allows you to:

  • reuse existing documents
  • generate a structured slide outline quickly
  • create a first PowerPoint draft automatically
  • focus your effort on improving content and layout rather than starting from scratch
